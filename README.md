# MailGuard AI — Gmail Spam & Email Category Classifier

## What it does

1. User signs in with Google.
2. The same Google authorization grants read-only Gmail access.
3. Flask retrieves recent inbox messages using Gmail API.
4. A TF-IDF + Logistic Regression model, trained on the supplied `email,label` dataset, predicts spam/not-spam.
5. A separate explainable keyword classifier assigns categories such as Personal, Promotional, Business, College, Finance, Social, Updates, or Other.
6. The web UI displays confidence, category, spam status, sender and subject.

## Important limitation about the category column

The supplied CSV contains only:
- `email`
- `label`

There is no human-provided category column. Therefore the `category` column generated by `train_model.py` is rule-based/pseudo-labelled. It is useful for a first version, but it is NOT a supervised category model trained on real category labels.

For a genuinely trained category classifier, create a dataset with:
`email,spam_label,category`
where category is manually verified.

## Setup

### 1. Create a Google Cloud project

Enable:
- Gmail API

Create an OAuth Client ID:
- Application type: Web application
- Authorized redirect URI for local development:
  `http://127.0.0.1:5000/auth/callback`

Put the credentials in `.env`.

### 2. Install

```bash
python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Copy dataset

Put the supplied CSV here:

`data/spam_or_not_spam.csv`

### 4. Train

```bash
python train_model.py
```

This creates:

`model/spam_model.joblib`

and:

`data/spam_dataset_with_category.csv`

### 5. Start

```bash
python app.py
```

Open:

`http://127.0.0.1:5000`

## Google OAuth notes

The app requests:
- openid
- email
- profile
- gmail.readonly

It does NOT request:
- gmail.send
- gmail.modify
- gmail.compose

Therefore the application is intentionally read-only.

For production, use HTTPS, a production database, encrypted token storage, CSRF protection, secure cookies and proper Google OAuth verification/publishing.
